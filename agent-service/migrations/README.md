# Agent 数据库初始化

初始结构版本为 1，定义在 app/models.py。执行 `python -m app.manage migrate --config config.local.json`；先创建独立空 MySQL 库，停止 Agent，仅运行一个初始化命令。不会修改 access-service 的数据库。

所有表显式采用 InnoDB、utf8mb4、utf8mb4_bin。包含唯一约束的模型也必须携带相同选项；字符串外键两端排序规则一致。数据库原有默认排序规则不影响新表。

初始化流程：获取 MySQL 连接级命名锁 → 检查空库或有效版本 → 按依赖顺序创建业务表 → 最后创建 agent_schema_version → 核对全部表、字段与外键 → 写入版本 1 并提交 → 释放锁。

重复执行不会重建表，而会检查版本和结构。没有有效版本的非空库、版本为空、不支持的版本或缺失结构均拒绝自动处理。不会自动删除表、覆盖数据或补建半成品。

MySQL DDL 可能隐式提交，不能保证整个初始化事务回滚。失败后可能残留业务表，但不会提前写入成功版本。先根据错误编号排查；只有在人工确认专用测试库无数据并明确授权后才能清理。不要以手工插入版本号跳过校验。

此次部署中用户已手动删除两个空表，后续按空库初始化，不启用恢复入口。未来结构变更仍须有序迁移、备份及回滚说明，不覆盖已有结构版本。
