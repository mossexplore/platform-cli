# WiseRec CLI 详细测试 skill

这是独立测试资料，不由 CLI 安装包部署。使用时以当前安装命令的 `--help` 核对语法；如果与本文不同，报告差异，不猜测缺失选项或服务端字段。

## 查阅路径

1. 先读 [共同规则](references/common.md)，核对运行环境、业务、权限和交互限制。
2. 在 [完整命令索引](references/index.md) 定位目标，读取对应命令详解。每条详解包含参数、边界、响应、错误、示例及证据，不必一次读取全部命令。
3. 全局选项、根命令和有独立行为的命令组见 [全局与命令组](references/global.md)。
4. 多步任务逐条读取必要命令；准确 ID 直接使用，名称有歧义时请用户选择。分页结果不自动等于完整结果。

## 执行与解释

只通过 `ml` 操作平台，不直接调用 HTTP、不手工拼接 businessid、不读写凭据或业务配置。按命令说明选择实际支持的输出模式，先检查退出码，再解释结果；有 JSON 输出不代表全部成功。

区分 CLI 已验证约束、服务端确认规则和未知限制。未设置客户端上限不等于服务端无限制；条目展示字段不等于完整响应。明确响应是原始平台包装、重组结果、纯文本还是文件产物。

写操作须匹配用户已授权的环境、业务和目标；涉及生产写操作时复述目标和参数并取得明确确认。超时或连接丢失先用只读命令核验，不自动重复启动、克隆、部署、上传或执行代码。

返回必要的环境、目标、实际命令和可观察结果。去除秘密与签名 URL；引用带时区时间时换算为北京时间 `YYYY-MM-DD HH:mm:ss`。源码证据仅用于维护，不是让 Agent 改用内部函数操作平台的许可。
