# `ml auth status`

显示当前环境的认证有效期，不显示敏感值。

## 使用前提

先核对 [共同规则](../../common.md) 中的环境、业务和认证要求。业务资源 ID 必须来自当前目标上下文。本地状态检查。

## 命令格式

```text
ml auth status [OPTIONS]
```

全局选项放在子命令之前；`[OPTIONS]` 仅代表下表列出的选项，不是字面输入。

## 参数与选项

| 参数 / 别名 | 类型 | 必填 | 缺省值 | 约束与用途 |
| --- | --- | --- | --- | --- |
| `--help` | 开关 | 否 | false | 显示本命令帮助并退出 |

参数表的 None 表示未指定，不应在命令行输入字面量 `None` 或 `null`。空字符串与缺省是否相同，以以下规则为准。

## 边界与组合规则

退出 0 不代表登录有效，必须检查 status；业务获取失败时 businessId 显示 -。

## 响应与展示

固定表格：profile/username/cn_name/department/businessId/status/remaining_minutes/acquired_at/expires_at/timezone；status=valid/expired，remaining_minutes 为向上取整且不小于 0 的整数；时间为北京时间字符串。

仅将明确标注类型和存在条件的字段视为本地实现保证；展示字段清单不等于完整接口 schema。未约束字段的类型、可空性和服务端枚举待接口契约或脱敏实测确认。

## 错误与核验

参数解析错误通常退出 2，命令捕获的业务/配置/响应错误通常退出 1；本页另有退出码说明时优先按该说明。检查退出码与 stderr，不能仅凭 stdout 有 JSON 或成功提示断定全部操作成功。认证提示和历史记录等全局行为见共同规则。

本地状态检查。有副作用的操作在超时或失联后先查询状态；不把不确定结果当作未执行。
