# `ml logout`

清除当前环境的本地认证信息。

## 使用前提

先核对 [共同规则](../common.md) 中的环境、业务和认证要求。业务资源 ID 必须来自当前目标上下文。停止相关保活并清除本地认证；用 auth status 核验。

## 命令格式

```text
ml logout [OPTIONS]
```

全局选项放在子命令之前；`[OPTIONS]` 仅代表下表列出的选项，不是字面输入。

## 参数与选项

| 参数 / 别名 | 类型 | 必填 | 缺省值 | 约束与用途 |
| --- | --- | --- | --- | --- |
| `--all` | BOOLEAN | 否 | `false` | 开关，无需参数值；清除所有环境的本地认证信息 |
| `--forget-browser` | BOOLEAN | 否 | `false` | 开关，无需参数值；同时清除专用 Edge Profile，之后登录可能需要重新输入验证码 |
| `--help` | 开关 | 否 | false | 显示本命令帮助并退出 |

参数表的 None 表示未指定，不应在命令行输入字面量 `None` 或 `null`。空字符串与缺省是否相同，以以下规则为准。

## 边界与组合规则

--all 作用于全部环境；--forget-browser 还清除专用 Edge Profile，后续可能重新验证码登录。

## 响应与展示

输出文本提示，不支持 JSON 输出选项；不存在可解析的统一 JSON 响应。

参数解析错误通常退出 2，命令捕获的业务/配置/响应错误通常退出 1；本页另有退出码说明时优先按该说明。检查退出码与 stderr，不能仅凭 stdout 有 JSON 或成功提示断定全部操作成功。认证提示和历史记录等全局行为见共同规则。
