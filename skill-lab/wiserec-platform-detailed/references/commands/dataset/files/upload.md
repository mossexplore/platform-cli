# `ml dataset files upload`

向指定目录追加文件

## 使用前提

先核对 [共同规则](../../../common.md) 中的环境、业务和认证要求。业务资源 ID 必须来自当前目标上下文。追加远端文件；不自动重试认证；用 ml dataset files list 核验，不盲目重传。

## 命令格式

```text
ml dataset files upload DATASET_ID LOCAL_FILE [OPTIONS]
```

全局选项放在子命令之前；`[OPTIONS]` 仅代表下表列出的选项，不是字面输入。

## 参数与选项

| 参数 / 别名 | 类型 | 必填 | 缺省值 | 约束与用途 |
| --- | --- | --- | --- | --- |
| `dataset_id` | TEXT | 是 | 无，必填 | 数据集 ID |
| `local_file` | PATH | 是 | 无，必填 | 检查可读；本地单个文件路径 |
| `--dir` | TEXT | 否 | `"/"` | 数据集内部目标目录 |
| `--timeout` | FLOAT RANGE | 否 | `1800` | ≥1；CLI 未设置上限；上传网络操作超时秒数 |
| `--output` / `-o` | TEXT | 否 | 未指定（None） | table 或 json；缺省读取当前环境 output_format |
| `--help` | 开关 | 否 | false | 显示本命令帮助并退出 |

参数表的 None 表示未指定，不应在命令行输入字面量 `None` 或 `null`。空字符串与缺省是否相同，以以下规则为准。

## 边界与组合规则

目录默认 /；拒绝空值、反斜杠、控制字符和 . 或 .. 路径段；重复斜杠归一化。 本地必须为可读普通单文件；文件名匹配 [A-Za-z0-9][A-Za-z0-9_.-]*，后缀仅 .txt/.csv/.zip/.tar/.gz/.json（不区分大小写）。允许大小恰好 2,000,000,000 字节，超过拒绝；空文件未被 CLI 拒绝。服务端精确 2GB 边界尚未确认。timeout 为网络操作秒数，并非完整上传总时限。

- `--timeout`：≥1；CLI 未设置上限；范围端点按表中包含性判断，越界由解析器拒绝

## 响应与展示

输出平台原始 JSON，未重组业务字段；服务端扩展字段可能继续增加。 成功要求 result.code 为整数 0；追加请求成功不等于文件处理完成。

仅将明确标注类型和存在条件的字段视为本地实现保证；展示字段清单不等于完整接口 schema。未约束字段的类型、可空性和服务端枚举待接口契约或脱敏实测确认。

## 错误与核验

参数解析错误通常退出 2，命令捕获的业务/配置/响应错误通常退出 1；本页另有退出码说明时优先按该说明。检查退出码与 stderr，不能仅凭 stdout 有 JSON 或成功提示断定全部操作成功。认证提示和历史记录等全局行为见共同规则。

追加远端文件；不自动重试认证；用 ml dataset files list 核验，不盲目重传。有副作用的操作在超时或失联后先查询状态；不把不确定结果当作未执行。
