# `ml train clone`

读取完整训练任务详情并创建副本。

## 使用前提

先核对 [共同规则](../../common.md) 中的环境、业务和认证要求。业务资源 ID 必须来自当前目标上下文。创建新训练任务；查询新名称并核对 ID，超时不重放。

## 命令格式

```text
ml train clone TASK_ID --name NAME [OPTIONS]
```

全局选项放在子命令之前；`[OPTIONS]` 仅代表下表列出的选项，不是字面输入。

## 参数与选项

| 参数 / 别名 | 类型 | 必填 | 缺省值 | 约束与用途 |
| --- | --- | --- | --- | --- |
| `task_id` | TEXT | 是 | 无，必填 | 源训练任务 ID |
| `--name` | TEXT | 是 | 无，必填 | 克隆后的新任务名称 |
| `--customize-config` | TEXT | 否 | 未指定（None） | 可选自定义参数，按字符串原样传递 |
| `--yes` / `-y` | BOOLEAN | 否 | `false` | 开关，无需参数值；跳过克隆确认 |
| `--help` | 开关 | 否 | false | 显示本命令帮助并退出 |

参数表的 None 表示未指定，不应在命令行输入字面量 `None` 或 `null`。空字符串与缺省是否相同，以以下规则为准。

## 边界与组合规则

taskId 与 name 非空；customize-config 缺省保留原配置，提供时按字符串传递；必须核对完整源任务。

## 响应与展示

输出文本提示，不支持 JSON 输出选项；不存在可解析的统一 JSON 响应。 新任务 ID 仅在响应有效时显示；没有 ID 不代表克隆未生效。

仅将明确标注类型和存在条件的字段视为本地实现保证；展示字段清单不等于完整接口 schema。未约束字段的类型、可空性和服务端枚举待接口契约或脱敏实测确认。

## 错误与核验

参数解析错误通常退出 2，命令捕获的业务/配置/响应错误通常退出 1；本页另有退出码说明时优先按该说明。检查退出码与 stderr，不能仅凭 stdout 有 JSON 或成功提示断定全部操作成功。认证提示和历史记录等全局行为见共同规则。

创建新训练任务；查询新名称并核对 ID，超时不重放。有副作用的操作在超时或失联后先查询状态；不把不确定结果当作未执行。
