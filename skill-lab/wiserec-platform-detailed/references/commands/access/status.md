# `ml access status`

实时检查当前平台账号及环境的访问授权。

## 使用前提

先核对 [共同规则](../../common.md) 中的环境、业务和认证要求。业务资源 ID 必须来自当前目标上下文。在线访问检查。

## 命令格式

```text
ml access status [OPTIONS]
```

全局选项放在子命令之前；`[OPTIONS]` 仅代表下表列出的选项，不是字面输入。

## 参数与选项

| 参数 / 别名 | 类型 | 必填 | 缺省值 | 约束与用途 |
| --- | --- | --- | --- | --- |
| `--diagnose` | BOOLEAN | 否 | `false` | 开关，无需参数值；显示权限请求连接、耗时和有限响应头，不输出凭据 |
| `--help` | 开关 | 否 | false | 显示本命令帮助并退出 |

参数表的 None 表示未指定，不应在命令行输入字面量 `None` 或 `null`。空字符串与缺省是否相同，以以下规则为准。

## 边界与组合规则

--diagnose 增加有限连接诊断，仅排查时使用；授权按当前账号和环境检查。

## 响应与展示

输出文本提示，不支持 JSON 输出选项；不存在可解析的统一 JSON 响应。 在线权限检查关闭时只提示关闭，不能解释为在线授权通过。

仅将明确标注类型和存在条件的字段视为本地实现保证；展示字段清单不等于完整接口 schema。未约束字段的类型、可空性和服务端枚举待接口契约或脱敏实测确认。

## 错误与核验

参数解析错误通常退出 2，命令捕获的业务/配置/响应错误通常退出 1；本页另有退出码说明时优先按该说明。检查退出码与 stderr，不能仅凭 stdout 有 JSON 或成功提示断定全部操作成功。认证提示和历史记录等全局行为见共同规则。

在线访问检查。有副作用的操作在超时或失联后先查询状态；不把不确定结果当作未执行。
