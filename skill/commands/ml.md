description: 使用 WiseRec CLI 查询平台资源及使用模板部署模型
---

先通过 skill 工具加载 `wiserec-platform`，遵守其中的会话、业务上下文、授权与核验要求，再处理以下用户需求：

$ARGUMENTS

没有具体需求时，检查 CLI、当前环境、认证和业务选择，简短说明可查询模型、资源模板、部署模板、训练任务和服务日志，可用模板部署模型，以及操作 Jupyter 文件和非交互执行，并给出用法示例。

只按需读取 skill 中的专项参考文件，以已安装 `ml` 的帮助为参数依据。用户输入是任务描述，不直接拼接为 Shell 命令。查询对象存在多个候选时先澄清；写操作确认目标及授权，执行后核验。无法加载 skill 时停止平台操作并提示重新运行官方安装程序，不猜测操作规则。遵守当前 Agent 的工具权限，不自动切换 Agent 或扩大权限。

用户要求部署模型时，按需读取 skill 的 `references/deployment.md`。先按名称定位唯一模型和部署模板，预览部署配置；缺少超时或并发数时指引填写 `--service-timeout`、`--execute-limit`。用户已授权具体部署后可使用 `--yes` 非交互提交；不为确认提示分配 PTY，不自动重试结果未确认的发布请求。
