# 知识库原始文件源码变更

Go CLI 继续使用 1.1.2 版本号。本次源码新增 `ml kb file list` 和 `ml kb file download`，支持分页或全量查询原始文件名、目录和知识条目 ID，并按 ID 下载单个原始文件。请使用包含本次变更的 CLI 构建。下载保留文件字节，遇到本地同名文件时自动加序号。

配套权限服务 1.1.3 签发独立的列表和下载票据。知识库网关 0.1.1 默认关闭文件操作，由管理员分别对环境、账号和库授予列表或下载权限。原有 Wiki 查询沿用已有配置。权限服务仍要求数据库结构 15，从上一源码版本升级无需结构迁移。先更新签票服务和网关，再分发启用知识库的 CLI。详情见 [网关部署指南](../deployment/kb-gateway配置部署与使用指南.md)。

预期 Windows x64 交付格式为每用户 MSI 和便携 ZIP，网关目标平台为 Linux amd64。真实 WeKnora 的文件列表、原始文件下载权限、生产 MySQL 和 Windows 安装升级应在正式交付前验证。本说明记录源码变更。
