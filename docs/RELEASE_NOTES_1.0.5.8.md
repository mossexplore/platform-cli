# 1.0.5.8 变更说明

当前为源码变更，尚未正式发布，不提供本次版本的正式下载附件或镜像。

相较 1.0.5.7，新增 `ml resource template list` 和 `ml resource template detail RESOURCE_TEMPLATE_ID`。资源模板支持分页及模板名称、环境、框架和类型筛选，详情关联查询框架包，分组展示框架参数及环境变量、Hosts、调度和启动配置。框架密码与 Secret 按用户要求原样展示，JSON 保留完整接口字段。

使用前需配置目标环境、登录并选择业务。请求使用当前环境的业务编码。命令为只读查询，不修改资源模板，不执行模型部署。既有命令语法保持不变。

本次不修改权限服务或数据库迁移。Windows 安装包、离线包、权限镜像及部署升级资料沿用上一正式发布入口，不代表本次已经构建或发布对应产物。

本地验证：CLI 测试 655 项通过、12 项跳过；权限服务使用 Python 3.12 测试 173 项通过；浏览器时区测试 3 项通过。新增资源模板测试 41 项通过，覆盖接口请求、环境业务隔离、框架联查、认证刷新、完整 JSON、原样敏感值及异常路径。使用手册结构与实际命令树检查通过；Wheel 元数据、包内版本、安装后 `ml --version` 均为 1.0.5.8，新模块包含在包中。

跳过的 CLI 测试不视为已验证；尚未进行真实平台接口联调、Windows 安装验证或正式发布工作流验证。


## 部署模板查询

同批变更新增 `ml deployment template list` 和 `ml deployment template detail DEPLOY_TEMPLATE_ID`。列表支持分页、框架包名称、环境和框架类型筛选；详情展示基本信息、健康检查及全部关联容器资源模板。关联查询返回全部匹配数据，按名称严格相等过滤；保留部分查询结果，失败、缺失或同名歧义返回非零状态。不会创建部署或修改模板。

部署模板新增测试 45 项通过；本批最终 CLI 回归 700 项通过、12 项跳过，权限服务回归 173 项通过，浏览器时区测试 3 项通过。手册全部 24 章结构及实际命令树检查通过；重新构建的 Wheel 包含部署模板模块，包元数据、包内版本及安装后的 `ml --version` 均为 1.0.5.8。未进行真实接口联调、Windows 安装验证或正式发布工作流验证。
