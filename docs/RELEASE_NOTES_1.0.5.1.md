# 1.0.5.1 源码变更说明

本次基于源码 1.0.5 改进 Web Studio 连接准备。此变更说明不代表已创建正式 Release；正式附件、镜像及发布状态以 GitHub Release 为准。

## 改进内容

- Web Studio 连接按配置路径、环境、平台地址、账号、业务、实例、网关路由及平台凭据隔离缓存，默认有效期为 3600 秒（1 小时）；无需常驻进程。
- 缓存命中后复用连接地址、Token 和具有完整作用域的 Cookie，省去实例查询、访问地址获取及 `/lab` 初始化三次串行请求。在线权限检查仍按配置逐条执行，业务请求头继续读取当前环境所选业务。
- `jupyter.connection_cache_ttl_seconds` 可配置为 0–3600 秒，0 禁用缓存。Cookie 有明确过期时间时，缓存提前失效；缓存命中不会滑动续期。
- `ml webstudio login ENV_ID --refresh` 显式重新建立连接；普通 login 也获取新凭据。退出登录清理对应环境缓存，`--all` 清理全部缓存；实例启停清理当前环境缓存。
- 文件锁合并并发连接发现与会话初始化；旧请求不能覆盖或删除已刷新的会话。
- 只读 GET 明确返回 HTTP 401 时最多刷新重试一次；403、网络超时、写操作、已开始修改后的请求及 WebSocket 握手不会自动重放。重定向或错误登录页使缓存失效。
- Jupyter 命令以 `目标Web Studio名称：STUDIO_NAME，envId：ENV_ID` 显示目标名称和实例 ID，缓存命中时同样显示；旧缓存首次使用时补查名称，保留既有会话。提示写入标准错误输出，JSON 标准输出保持可解析。
- 普通诊断输出不再包含带 Token 的完整访问地址。

## 使用前提与兼容性

保持现有平台登录、业务选择及 Web Studio 网关配置。新增缓存位于用户配置目录下 `webstudio-connections`，包含短期敏感凭据，不应分享或提交。POSIX 目录和文件权限分别为 0700 和 0600；文件采用原子替换，Windows 沿用用户配置目录的访问控制并使用系统文件锁。

已有命令与参数保持兼容，仅增加可选刷新参数和缓存配置。不涉及权限服务数据库结构、迁移或生产部署。Jupyter exec 仍为每次调用创建独立 Kernel，本次未改变 Kernel 生命周期或文件传输方式。

## 验证范围与限制

- CLI 自动化测试覆盖缓存命中、跨解释器 Cookie 恢复、上下文隔离、到期、关闭缓存、并发刷新、权限拒绝、不重放、退出登录、启停清理和凭据脱敏。
- 权限服务测试在 Python 3.12 环境执行；浏览器时间预设测试覆盖三个时区。
- 临时本地 Jupyter 服务验证文件操作及非交互执行完整链路。
- 本地 Wheel 检查包元数据、包内版本、安装后 `ml --version` 及新模块包含情况。
- 未进行真实远端 Web Studio 网关联调、远端耗时测量、Windows 实机缓存权限验证或 MySQL 生产环境验证；未运行正式 Release 工作流，未生成正式 Windows 分发包或权限服务镜像。

远端网关若不接受跨进程 Cookie 恢复，可暂将缓存有效期设为 0，并通过显式刷新重建连接。实际性能收益取决于平台、网关及网络时延。
