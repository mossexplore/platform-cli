# 产品版本号管理

## 唯一维护入口

仓库根目录的 `versions.toml` 是唯一人工维护的产品版本来源：

```toml
[components]
cli = "1.0.7.12"
access = "1.0.7.12"
agent = "1.0.7.12"
notifier = "1.0.7.12"

[compatibility]
agent_cli = "1.0.7.12"
```

四个产品这次使用相同版本，以后可以分别递增。只修改某个产品时更新该产品的值；新增 CLI 命令仍按项目约定递增 CLI 补丁号。同一次变更已经递增时不重复增加。

`compatibility.agent_cli` 记录 Agent 经过测试搭配的 CLI 版本，不代表 Agent 自己的版本，也不应在未验证时随意更新。Agent 的 `/api/health` 同时提供自身 `version`、实际安装的 `cli_version` 和记录的 `tested_cli_version`，页面只展示自身版本。

## 同步与检查

在仓库根目录运行：

```bash
python scripts/sync_versions.py
python scripts/sync_versions.py --check
```

推荐使用项目的 Python 3.12 环境。CLI 的 Python 3.9/3.10 构建环境通过构建依赖 `tomli` 读取 TOML。

第一条同步派生文件；第二条只检查、不修改文件，不一致时失败。修改版本后应一起提交 `versions.toml` 及所有受影响的派生文件，不手工分别维护下面的版本值。

| 产品 | 派生文件 | 运行时版本来源 |
| --- | --- | --- |
| CLI | 根 `pyproject.toml`、`src/wiserec_cli/__init__.py` | 安装包内的 `wiserec_cli.__version__`，供 `ml --version` 与请求头使用 |
| 权限管理系统 | `access-service/VERSION`、`access-service/app/_version.py` | 自身包内的 `app._version.__version__`，供管理页面使用 |
| Agent | `agent-service/pyproject.toml`、`agent-service/app/_version.py` | 自身包内的版本，供健康接口和页面使用 |
| 权限通知助手 | `permission-notifier/pyproject.toml`、`permission-notifier/src/permission_notifier/__init__.py` | 自身包内的版本，供心跳上报与页面左下角“高级设置”同一行右侧使用 |

Python 版本文件头注明自动生成。`pyproject.toml` 的其他依赖、配置内容仍按原方式维护，脚本仅同步项目版本。

## 打包后的版本

从完整仓库构建 CLI、Agent、通知助手 Python 包时，构建入口会先执行同步。CLI 源码分发包带有 `versions.toml` 和同步脚本，可以重新构建；它不包含其他服务的源码。Agent、通知助手的独立源码包携带已同步的自身版本，离开仓库后仍能安装，不需要读取仓库根文件。

通知助手的 `scripts/build.py` 在完整仓库执行时也会先同步，再生成带相同版本的 ZIP 文件及 `release.json`。独立安装包带有 `setup.py`，可按原安装方式安装。

权限系统 Docker 构建前必须先同步。镜像构建参数 `VERSION` 用于镜像标签和元数据，正式值必须与包内权限系统版本相同，否则 Docker 构建失败；`development` 仅用于开发镜像。运行时页面始终读取包内版本，修改环境变量不能伪装成其他版本。

程序运行不依赖仓库根文件，也不把 CLI 版本当作 Agent 或权限系统版本。数据库结构版本与通信协议版本沿用各自原机制，不随产品版本自动递增。

## 发布与文档

版本配置表示源码目标值，不代表已经发布。页面显示的是实际运行程序携带的版本，旧程序或旧镜像不会因为修改仓库文件就自动更新。

CI 在正式套件构建、权限镜像构建、通知助手构建前执行版本一致性检查。当前 `release.yml` 仍是 CLI、权限系统与通知助手的统一正式交付流程，保留三者同号门禁；Agent 尚未加入该正式套件。以后按不同版本独立正式发布，需要相应的组件发布流程，不能绕过现有门禁，也不能把版本文件更新称为正式发布。

发布说明、下载地址和历史 Release 分别维护，历史附件与标签不改写。当前已发布下载入口保持原版本。本次没有触发正式发布、部署服务或执行数据库迁移。
