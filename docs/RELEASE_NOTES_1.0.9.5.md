# CLI 1.0.9.5 变更说明

相较 CLI 1.0.9.4，新增 `ml train history detail TASK_ID JOB_ID`，支持 WiseRec 和 WiseMLOps 执行记录详情。分布式训练展示 worker、server 等角色，首列完整展示角色作业 ID，开始时间按北京时间显示，JSON 保留原始字段。

执行记录普通日志下载统一先检查存在性，适用于普通训练和分布式训练。不存在时按作业提交手动归档并等待；每次获取下载链接前必须确认日志存在。同次命令内同一作业最多提交一次归档，超时或失败返回非零退出码。

分布式日志支持 `--role-job-id` 精确选择，或通过 `--select 1,2`、`--select all` 选择角色；交互终端可按编号选择，脚本和 JSON 模式须显式选择。`--wait-timeout` 默认为每条日志 120 秒，0 表示不等待。批量下载保留已成功文件并汇总其余失败，不覆盖同名文件。

使用前需登录、选择当前环境的业务，并准备已存在的下载目录。普通训练保留原命令用法，但增加执行记录查询、日志检查及必要的归档等待。分布式训练必须明确选择角色。plog 沿用原流程，不接受角色选择或自定义归档等待时间；执行实例日志命令不变。

本地验证覆盖普通及分布式日志请求顺序、当前业务请求头、归档去重、超时、角色选择、批量部分失败、分页详情及时间展示。CLI 与权限服务回归、浏览器时区检查通过；隔离配置构建的验证 Wheel 已检查新模块、包元数据及 CLI 运行版本。

此为源码变更，未正式发布，也未变更生产部署。真实 WiseRec、WiseMLOps 日志归档和文件下载联调尚未完成；Windows 安装、真实 MySQL 和正式发布附件尚未在本次验证。正式安装包、离线包及发布附件仍需经过正式发布流程。
