# 1.0.5.4 源码变更说明

基于源码 1.0.5.3 新增 `ml service logs SERVICE_ID` 引导式日志查询。正式版本下载入口保持不变，本次不执行正式 Release 或生产部署。

## 使用方式与兼容性

先配置环境、登录并选择业务。主机查询支持分页，唯一主机和文件自动选择，多个候选项交互选择。日志类别无默认值，通过交互或 --type 指定。

支持 --pod、--file、--keyword/-k、--lines/-n、--list、--no-input 以及高级检索选项。默认读取末尾 200 行，正文可重定向。rtc_python 主机自动在两种日志请求中携带 data.type，rtc 主机不携带；两个接口使用同一日志类别。未知主机类型报错。

旧的 service host logs list/search 参数与行为保留。没有新增配置或数据库迁移。

## 验证范围与限制

测试覆盖请求体、业务请求头、分页、两类主机、选择与取消、非交互报错、参数冲突、文件列表、正文输出及旧命令兼容性。核验命令树、手册结构、Wheel 元数据及安装后的 CLI 版本。

未进行真实平台接口联调，未生成正式 Windows 分发包或权限系统镜像。
