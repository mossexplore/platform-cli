# CLI 1.0.9.6 变更说明

MLOps 环境新增对现有训练任务启动、取消、软删除、克隆、详情、自定义参数更新和 YAML 配置导出命令的支持。算法仓列表、下载和克隆也可在 MLOps 环境执行。特征任务新增列表、执行记录和执行日志搜索，详情继续可用。

新增支持的操作从当前 MLOps 环境获取平台地址和已选业务，沿用 WiseRec 的参数、输出和确认流程。训练启动直接提交任务。取消、软删除和克隆默认询问确认。MLOps 的训练列表继续使用其现有接口，执行实例和执行记录继续使用已兼容的命令。

使用前在 CLI 配置中将目标环境的 `platform_type` 设为 `mlops`，切换到该环境并登录、选择业务，再用 `ml tree` 查看可用命令。环境禁止命令策略仍适用。

本次为源码变更。验证使用本地测试和模拟平台请求，未在真实 MLOps 环境执行写操作，未发布正式安装包。
