# v1.0.7.10 — CLI、权限管理系统与权限通知助手

三个组件统一使用 **1.0.7.10**，分别安装。相较上一正式版 **v1.0.7.7**，本版包含 CLI 服务测试能力、权限控制台改进及通知助手配置与诊断界面重设计。助手源码、依赖及个人配置不进入 CLI 安装包。

## 主要变化

- CLI 新增 `ml service mock SERVICE_ID` 与 `ml service host mock SERVICE_ID --pod-ip POD_IP`，支持 `--transmission-tag 0|1`；使用服务文档默认样例或 `--request-sample-file PATH` 指定 UTF-8 JSON 文件。主机测试从查询结果读取节点 ID 和地址，逐节点完整展示结果；主机列表支持按 Pod IP 查询。平台请求使用当前环境选中的业务 ID，失败、超时或断连不自动重放测试。
- CLI 将 Notebook 校验依赖延迟至实际使用时加载；补充 OpenCode、codeagent 的技能和 `ml` 命令资源安装。具体命令、使用前提与参数见 `CLI-reference.md`。
- 权限管理系统优化导航分组、页面布局和个人通知管理，增加连接、凭据与通知状态展示、筛选分页和通知操作审计；个人通知仍仅配置的通知所有者可管理，不改变审批权限。
- 权限通知助手提供 CMD 安装及卸载入口，修复无控制台启动日志问题；采用侧边菜单与紧凑布局，分别管理连接、消息配置、测试与诊断、发送记录和高级设置。Token 与 auth 支持直接替换、掩码显示及主动查看。
- 测试消息直接调用消息接口，内容可编辑，支持接收人选择、响应体脱敏展示和错误定位。发送成功判据为 HTTP 2xx 且响应 JSON 顶层 `status` 为 `ok`；接口接受不代表实际送达。
- 助手将配置与发送记录拆为 `assistant.json`、`send-records.json`，自动迁移旧格式。发送记录展示任务 ID、发送时间、来源、接收 UID、申请人、账号、申请时间及状态；申请字段从权限系统消息解析，无法解析时显示 `-`。默认查询最近 72 小时，进入记录页更新结束时间至当前北京时间，精确到秒。

CLI 联网安装要求 Python 3.9+，离线安装目标为 Python 3.12 x64；两者均不包含 Python 或 Microsoft Edge 本体。助手要求 Windows、Python 3.12 及可获取依赖的网络，属于源码联网安装包，不是免安装 EXE 或离线依赖整包。权限镜像不包含 MySQL 或 Jupyter Server，需连接已有 MySQL 8.x。

助手解压后运行 `install.cmd`。升级前退出旧助手并备份个人目录下的数据；无需先卸载，重复安装会更新程序并保留配置。安装后使用桌面“权限通知助手”快捷方式启动，打开 `http://127.0.0.1:18765`。首次升级旧格式数据后，应同时备份两个 JSON 文件；不要让新旧助手同时运行。凭据保存在个人文件中，不随安装包分发。

## 升级与兼容性

已比较 v1.0.7.7 与本版的迁移、通知结构和模型：**数据库结构均为 12，无结构变化，从 1.0.7.7 升级无需执行迁移或重新创建管理员**。先独立库恢复演练，维护窗口停写并做最终数据库及配置备份，再替换镜像验收。保留原 service.env、外部数据库及管理员。同结构可停写后回滚至 1.0.7.7 镜像；若恢复数据库备份，备份后的写入会丢失。完整命令见 `Docker-upgrade-1.0.7.10.md`。

仍使用结构 11 的旧部署，须先按历史 1.0.7.1 → 1.0.7.7 指南完成备份与显式迁移，不能直接套用本次同结构升级步骤。新库仍按部署指南初始化。发布和出包均不自动升级生产，也不调整版本准入策略。

CLI 自定义服务报文使用文件参数 `--request-sample-file`，不支持开发期间的 `--request-sample` 内联参数。消息接口若仅返回 HTTP 200 而没有顶层 `status: ok`，助手将不再判为接受成功；升级前请确认接口协议。测试消息使用表单当前内容，不自动保存表单配置。Token/auth 保存空值会清除对应凭据。

## 验证范围与限制

发布前本地验证：CLI 1159 项通过、12 项跳过，权限服务 259 项通过、1 项跳过，助手 62 项通过，Node 回归 13 项通过；Wheel 元数据与 `ml --version` 均为 1.0.7.10。CLI 手册 32 章结构及无版本信息检查通过，新升级指南的 Docker 命令块与基准一致。

发布工作流门禁包括 CLI、权限服务与助手测试，时区和通知状态回归，临时 MySQL 通知并发验证，Windows CLI 联网/离线安装、重复安装及从正式版 1.0.7.7 升级，助手安装及本机 HTTP 启停，以及同摘要 Docker 镜像健康、授权、日志、图表数值、挂载重启与 save/load 验证。草稿附件会在独立运行环境重新下载，复核全部 14 项附件的哈希、版本、源提交、文档、包隔离和 Docker 镜像身份。实际结果以关联工作流为准；草稿不等于正式发布。

真实业务平台、远程 Jupyter、真实消息接口与最终消息送达未联调；Windows 用户桌面的托盘交互和登录自动启动仍需实际环境验收。跳过的测试不视为通过，模拟接口接受不代表用户已收到消息。
