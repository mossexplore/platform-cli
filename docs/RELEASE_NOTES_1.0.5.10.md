# 1.0.5.10 变更说明

当前为源码变更，尚未正式发布。本次未生成正式下载附件或镜像，正式下载入口继续指向已发布版本。

相较源码 1.0.5.9，新增 `ml featureset wide export SET_ID` 和 `ml featureset model export SET_ID`，将特征集的特征导出为一个 CSV 文件。使用前须选择环境、登录并选择当前环境的业务；请求头和查询参数使用同一业务 ID。

`--lang` 默认 `zh_cn`，支持 `en_us`；`--file PATH` 指定保存路径，父目录须已存在。默认使用服务端文件名，缺失时回退为 `featuresInSet.csv`。已有同名文件时依次添加 ` (1)`、` (2)`，并发保存也不覆盖文件。原样保存解压后的 CSV，保留编码、BOM、换行、全部列和字段值。下载失败清理临时文件，JSON 错误、HTML 登录页面及空响应不作为 CSV 保存。

默认摘要显示绝对路径和按 1024 换算的易读大小，最多两位小数；`--output json` 输出包含整数 `bytes` 的结构化摘要。既有命令语法兼容，不涉及权限服务或数据库结构变更。

本地验证：CLI 测试 878 项通过、12 项跳过，其中新增导出测试 32 项；权限服务在 Python 3.12 下 189 项通过；浏览器时区测试 3 项通过。模拟 HTTP 下载覆盖 gzip、JSON 类型误标、错误响应、重名竞争和失败清理。手册全部 25 章结构、实际命令树、差异检查通过；Wheel 元数据、包内版本及安装后的 `ml --version` 均为 1.0.5.10，新增模块和两个命令入口已核验。跳过的测试不视为已验证。真实平台中英文导出、空特征集、Jupyter 联调、Windows 安装和正式发布工作流尚未验证。本地打包不等于正式发布，未自动升级生产服务。
