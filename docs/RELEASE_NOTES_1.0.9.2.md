# CLI 1.0.9.2 变更说明

此为源码变更，尚未执行正式发布流程，不代表已生成下载附件。权限管理系统、Agent、权限通知助手版本不变；Agent 已验证的 CLI 搭配版本记录保持不变。

相较 CLI 1.0.9.1，新增 WiseRec、MLOps 共用的 `ml train instance logs download TASK_ID JOB_ID`：请求日志归档，归档完成后按记录编号选择一份或多份日志，逐份获取 OBS 下载链接并保存 ZIP。未完成归档时稍后重新执行命令；仅 status=1 可下载。支持英文逗号分隔、中文逗号纠错、编号去重与状态校验。脚本和 Agent 可传 `--select 2`、`--select "1,3"` 或 `--select all`，跳过编号提示。时间按北京时间展示，同名归档分别编号，批量部分失败继续其余文件并返回非零退出码。

训练历史记录日志下载（普通日志与 plog）和执行实例日志下载统一使用 `--directory DIR`，目录须已存在，默认当前目录。原日志下载 `--file PATH` 参数移除，已有脚本应改为保存目录，文件自动命名并以 ZIP 后缀保存，同名文件不覆盖。其他命令的 `--file` 参数不受影响。

使用前须登录、选择当前环境业务，并有对应命令和平台权限。归档成功不代表训练结束，不保证包含归档之后产生的新日志。不涉及权限系统数据库结构或生产部署变更。真实 WiseRec/MLOps 业务接口、归档等待及 OBS 下载尚需在可访问环境联调；本地模拟测试不能替代真实业务验收。

CLI 运行时统一从当前账号的用户目录读取配置。Windows 固定使用 `%APPDATA%\ml\config.json`，移除 `--config` 和 `ML_CONFIG` 配置入口。安装程序负责更新配置，并清理所选 Python 和安装虚拟环境中已识别的 wiserec-cli editable 安装。
