# 1.0.5.6 源码变更说明

基于源码 1.0.5.5 新增数据集目录查询与单文件追加命令。本次为源码提交和本地 Wheel 验证，不代表正式 Release，正式下载入口保持不变。

## 能力与兼容性

- 新增 `ml dataset files list DATASET_ID --dir REMOTE_DIR`，默认查询根目录。表格上方显示当前位置，完整路径按当前目录拼接服务端相对路径，更新时间显示北京时间。
- 新增 `ml dataset files upload DATASET_ID LOCAL_FILE --dir REMOTE_DIR`，自动查询数据集名称，以 Multipart 文件流上传，终端显示发送进度。根目录上传使用空目录字符串。
- 沿用当前环境和业务配置，请求头与请求体使用当前选中业务。JSON 保留响应的额外字段，目录 JSON 另包含 currentDir。
- 文件名限定为英文字母或数字开头，随后可包含英文字母、数字、下划线、连字符和点。支持 txt、csv、zip、tar、gz、json。2GB 精确边界尚待平台确认，当前采用保守的 2,000,000,000 字节上限。
- 上传网络操作默认超时 1800 秒，可用 --timeout 设置；不自动重放上传。超时或断连后需要查询目录核实，避免重复写入。

使用前配置环境、登录并选择业务。无数据库迁移或权限服务部署。

## 验证与限制

验证目录请求、相对路径、北京时间、额外字段、Multipart 实际编码、文件名及大小边界和上传认证拒绝不重放；执行 CLI、权限服务与浏览器时间预设测试，并核验本地 Wheel 元数据及安装后的 ml --version。

未进行真实平台上传、2GB 文件或 MySQL 环境联调。上传成功判断暂沿用平台 result.code 为整数 0 的约定；上传响应、异步处理、同名覆盖及压缩包处理规则尚待真实接口确认。hasMore 为 true 时明确提示不完整，未猜测分页协议。未执行正式 Release 工作流，未生成新的正式 Windows 包或权限服务镜像。
