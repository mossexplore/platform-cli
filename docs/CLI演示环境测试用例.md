# CLI 演示环境测试用例

本文件记录设计对应的自动化验收范围。运行结果和平台限制见 [测试报告](CLI演示环境测试报告.md)。

## 1. 测试入口

正式回归：`python -m pytest tests -q`。Jupyter 测试需显式启用独立本地服务，不连接真实业务平台。

演示回归：在独立开发虚拟环境安装核心、扩展、pytest 与 Jupyter 可选依赖后执行：

```bash
python -m pip install -r access-service/requirements.lock
python -m pytest devtools/mock-platform/tests tests/test_execution_context.py -q
```

权限服务：`PYTHONPATH=access-service python -m pytest access-service/tests -q`。

前端时区：`node --test access-service/tests/test_time_presets.cjs`。

## 2. 正式上下文与产物隔离

对应 `tests/test_execution_context.py`。

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| 无网络上下文查询 | 不登录执行 context --json | 可解析 JSON，模式与 profile 正确 |
| 地址脱敏 | 配置含用户名、密码、查询 Token 和片段 | 输出不包含敏感内容 |
| 忽略演示环境变量 | 正式进程设置失效演示路径 | 仍为真实平台，不导入演示模块 |
| 嵌套包检查 | ZIP 内嵌包含模拟模块的 Wheel | 检查失败，不放行 |
| 干净安装 | 源码目录外安装正式 Wheel | 版本正确，无法导入模拟提供者 |
| sdist 检查 | 构建并检查源码分发归档 | 无 devtools、演示脚本、测试和工作数据 |

## 3. 业务命令契约

对应 `devtools/mock-platform/tests/test_demo.py`；所有 invoke 都启动新的真实 CLI 子进程，不替换 Runtime 或直接伪造命令输出。

覆盖 context、环境、登录状态、业务目录、权限、用户、配置、训练列表与实例历史、算法、数据集、模型来源、资源模板、部署模板、服务、特征集、离线实验、Swanboard、WebStudio 列表、Ping 和历史。

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| 查询与分页 | 列表第二页、详情、各类关联查询 | 响应能被正式业务解析器消费 |
| 启动与完成 | start、history、逻辑时间推进 | 实例数增加，新进程可见成功状态 |
| 环境隔离 | demo-dev 写入后切换 demo-test | 写入不跨环境出现 |
| 克隆与删除 | 算法克隆、训练克隆、软删除 | 新 ID 可查询；删除后列表隐藏 |
| 参数修改 | 修改 customizeConfig | 参数改变，算法等其他配置保持 |
| 取消 | 启动后取消并查询 | 实例状态变为取消 |
| 部署预览 | model deploy --dry-run | 服务数不变 |
| 部署提交 | model deploy --yes | 服务数增加，可查询主机和记录 |
| 实验克隆 | 指定新实验名称 | 新记录持久化，不复制未声明的 trial 历史 |
| 日志 | 指定 Pod、集群、日志文件 | 返回可检索日志正文 |
| 业务选择 | 选择另一团队 | 数据来自新业务范围 |
| 退出与历史 | 清理历史、logout --all | 登录状态查询失败，状态文件限定工作区 |

## 5. 场景与故障边界

对应 `test_demo.py` 和 `test_isolation.py`。

| 用例 | 预期 |
| --- | --- |
| empty | 数量为 0，正常空列表 |
| large | 数据量超过默认分页，数量准确 |
| 真实权限拒绝 | 撤销测试权限服务授权后，业务调用被拒绝且无写入 |
| 真实版本封禁 | 权限服务配置封禁当前版本，阻止业务写入 |
| partial-failure | 指定请求失败一次，下一次恢复 |
| malformed-response | 响应不满足契约时返回错误 |
| expired-session | 显示过期，下一业务调用刷新且 JSON 不被提示污染 |
| 未知接口/错误方法 | 明确未实现，不返回空成功 |
| 外部地址/错误端口/HTTP | 传输拒绝，不访问真实业务网络；显式权限服务接口除外 |
| 外部配置 | 启动前拒绝，不在外部目录创建历史 |
| 跨业务与错误 Cookie | 拒绝请求 |
| 数据库损坏 | 演示启动失败，正式 CLI 仍能运行 |
| 扩展损坏 | 正式进程不尝试导入扩展 |
| 符号链接/已有目录 | 拒绝危险管理操作，不覆盖外部文件 |
| 并发启动 | 多个事务产生唯一作业，无丢失写入 |
| 重置确认 | 无 --yes 拒绝，确认后保留外部文件和 exports |
| 后台保活 | 使用模拟传输及当前业务身份 |
| 账号切换 | 清除原凭据，重新建立新账号目录和选择 |

## 6. 真实 Jupyter

对应 `test_jupyter_demo.py` 与原有 `tests/test_jupyter_live.py`、`test_jupyter_agent_live.py`。

- 在独立临时目录启动真实本地服务，检查前缀和 Token。
- 通过演示 WebStudio 启动、登录、选择，进入 Jupyter。
- 验证 doctor、目录创建、文件上传、读取和下载，比较实际字节。
- 执行 Notebook，检查保存的输出包含真实内核结果。
- 执行 POSIX 子进程，检查真实 stdout。
- 停止 WebStudio 后拒绝继续使用连接。
- 查询本地服务状态，通过认证 shutdown 接口停止自己登记的服务。
- 原有联调补充成功/异常/超时/禁用 stdin、WebSocket 和终端生命周期。
- 清理临时进程、内核和连接登记，不在用户默认目录写缓存。

## 7. 打包与安装

- 原正式 Windows 脚本保留参数和命名，新增构建后检查。
- 正式 Wheel/sdist 检查文件和依赖，嵌套 ZIP 递归检查 Wheel。
- 独立构建演示联网和离线包。
- 源码目录外解压并安装，执行包内同名 ml，验证 context 和业务列表。
- 离线安装设置 PIP_NO_INDEX，禁止从包索引补依赖。
- 独立 GitHub 工作流补充 Windows 原生演示安装验证，不作为正式发布流水线依赖。

## 8. 真实权限联调

对应 `test_permissions.py`，使用仓库权限服务实际应用、独立 SQLite 和真实 TCP，不对权限判定打桩。测试数据库与任何生产授权库无关。

- 放行后查询权限数据库，核对用户名、环境、当前 businessid、命令、版本及请求/调用标识。
- 撤销授权后启动训练失败、拒绝日志落库，模拟业务状态完全不变。
- 服务端版本策略封禁后拒绝业务命令，日志记录实际版本原因。
- 权限服务不可用时写入停止，context 仍可离线查看。
- 未授权账号、关闭权限配置、模拟权限域名、缺少账号均拒绝。
- 网络允许列表只开放指定权限服务的三个精确 POST 接口；管理路径、查询串和错误方法拒绝。
- 管理变更和保活同样经过真实授权；仅本地查询和安全清理无需在线授权。
