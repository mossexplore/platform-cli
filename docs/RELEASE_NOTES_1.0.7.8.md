# 1.0.7.8 CLI 开发说明（尚未发布）

相较 1.0.7.7，将 Notebook 执行模块及 `nbformat` 校验依赖改为实际使用时加载。版本查询、帮助、命令树、普通业务命令及 Jupyter 非交互执行不再因命令注册而加载 Notebook 校验依赖。

命令名称、参数、认证、权限校验和业务选择方式不变。Notebook 执行仍使用原有依赖完成读取、校验及输出保存。权限服务、本地通知助手和数据库结构未修改。

新增独立进程回归检查，验证普通命令不加载 `nbformat`、`jsonschema`，并验证协议解析可以独立于 Notebook 校验依赖使用。验证不包含真实平台、真实 Jupyter Server 或 Windows 原生联调；本机启动耗时不代表其他环境的性能保证。

本次仅更新 CLI 源码及包版本，未发布正式 Release、Windows 安装包或 Docker 镜像。正式下载入口继续使用 1.0.7.7。
