# 1.0.7.5 CLI 开发说明（尚未发布）

新增 `ml sample-task list`，默认查询旧任务管理，使用 `--source new` 查询新任务管理。支持分页、任务名称、创建者、修改者和重复类型筛选；旧版支持状态筛选，新版默认降序查询。请求体和请求头均使用当前环境已选业务。

表格展示中文类型和北京时间，完整保留任务 ID；JSON 使用统一分页结构并保留原始任务字段。新版兼容一维和二维任务列表，异常响应返回非零退出码。

使用前需选择环境、登录并选择业务。本次 CLI 补丁版本递增，权限服务与数据库结构未修改。验证范围为模拟 HTTP、CLI 自动化和本地 Wheel 检查，未进行真实平台或 Windows 原生联调，未发布正式 Release。
