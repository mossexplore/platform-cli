# 1.0.5.3 源码变更说明

基于源码 1.0.5.2 新增模型溯源查询并修正模型大小显示。本次为源码更新，不代表正式 Release；正式下载附件及平台要求以 GitHub Release 为准。

## 新增能力与修正

- 新增 `ml model source MODEL_ID`，先查询模型详情，再使用 `result.sourceId` 查询来源模型信息。
- 展示输出名称、原始 modelVersion、敏感、业务编码、发布状态、北京时间、描述、来源和存储桶。
- 支持 `--output table|json` / `-o`，默认沿用当前环境配置；JSON 保留来源接口完整原始响应和扩展字段。
- 模型详情大小改为读取 pkgSize，沿用字节单位转换。

## 使用前提与兼容性

需要配置环境、登录并选择业务。两步查询使用当前环境接口地址及所选业务请求头。

模型详情和溯源均要求 result.code 为整数 0；缺失或其他值将报错。模型详情缺少有效 sourceId 时无法溯源。此项收紧了此前对详情缺失 code 的兼容行为。

没有新增配置项或数据库迁移。本次不部署权限服务，也不修改正式版本下载入口。

## 验证范围与限制

自动化测试覆盖两步调用顺序、来源标识传递、当前环境与业务隔离、业务错误与缺失字段、完整 JSON、中文标签、北京时间及模型包大小展示。本地检查命令树、手册结构、Wheel 元数据及安装后的 CLI 版本。

未进行真实平台接口联调，未执行正式 Release 工作流，未生成正式 Windows 分发包或权限服务镜像。
