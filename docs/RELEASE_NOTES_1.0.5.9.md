# 1.0.5.9 变更说明

当前为源码变更，尚未正式发布，不提供本次版本的正式下载附件或镜像。已发布版本下载入口继续指向上一正式版本。

相较源码 1.0.5.8，新增 `ml model deploy MODEL_ID --template DEPLOY_TEMPLATE_ID`。部署模板及关联容器资源模板必选；CLI 查询模型、组件、资源、推理框架和真实租户后组装发布请求，全部关联资源参与部署。支持部署预览、QPS、更新模式、健康检查模式和端口、服务文档文件及非交互确认。

各区域实例数固定提交为字符串 "1"，不继承资源模板实例数；不配置弹性伸缩。框架配置必须为非空 JSON 对象，参数及 Secret 原样传递，完整预览 JSON 也包含原值。自定义启动命令按资源模板原样传递。服务名称及服务版本分别使用模型名称及模型版本。

使用前须选择环境、登录并选择业务，模板须包含有效的必填参数和唯一关联资源。发布前展示摘要并确认，脚本提交须指定 `--yes`。发布请求不自动重放；超时、认证拒绝或响应异常导致结果未确认时，应先查询服务。接口 code 为 0 判定成功，非零判定失败，不解析 des 文本。

既有命令语法保持兼容；本次不修改权限服务、数据库结构或迁移。正式发布前仍需执行统一工作流并独立核验附件，不能把本地 Wheel 当作正式发行包。
