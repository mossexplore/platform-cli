# 1.0.5.7 源码变更说明

基于源码 1.0.5.6 新增本地命令历史。本次为源码提交及本地 Wheel 验证，不代表正式 Release，正式下载入口保持不变。

## 能力与兼容性

- 新增 ml history，默认查看最近 20 条；list 支持数量、内容、环境、结果筛选及 JSON 输出，show 查看详情，delete 删除一条，clear 按环境和北京时间范围清理。
- 历史以 UTF-8 JSONL 文本保存在配置文件同级目录，不使用数据库。最多保留最近 1000 条，清理后不重用序号；使用跨进程文件锁和原子替换保护并发更新。
- 自动保存执行结果及脱敏命令，不保存输出和文件内容。支持 --no-history 或 ML_HISTORY=0 禁用自动记录，任意 Jupyter exec 参数整体隐藏。
- 历史命令无需登录或有效的平台配置内容，不触发平台访问。非交互清理需 --yes。保存失败只告警，不影响原命令。
- 包含此前移除表格时区提示及文件夹整行黄色显示的改进。

无新增依赖或数据库迁移，不部署权限服务。历史不会上传至平台，不自动重执行命令。

## 验证与限制

本地测试覆盖成功、失败、解析错误、中断、环境切换、禁用记录、脱敏、筛选清理、1000 条容量、损坏尾行及多进程并发；执行 CLI、权限服务和浏览器时间预设测试，并核对 Wheel 元数据及安装后 ml --version。

尚未在真实 Windows CMD/PowerShell 环境验证文件锁，也未进行真实平台业务或 MySQL 联调。强制杀进程或断电可能缺少本次记录，不记录执行中状态。未执行正式 Release 工作流，未生成新的正式 Windows 分发包或权限服务镜像。
