# 1.0.7.3 CLI 开发说明（尚未发布）

新增 `ml feature-task list`，分页查询当前环境、当前业务下的特征任务。支持任务名称、任务类型、创建者组合筛选，默认查询第 1 页、每页 10 条。业务 ID 读取当前环境的已选业务，同时写入请求体和业务请求头。

表格展示完整任务 ID、任务名称、中文任务类型、业务场景、状态、创建者、修改者、北京时间、可读大小和描述。JSON 保留完整任务记录及原始值。其他查询字段使用平台默认值，不提供修改选项。

沿用原有认证和业务选择流程，使用前需选择业务。无配置或数据迁移；权限管理系统本次未修改。此前 Wheel 构建暂存目录清理修复继续保留，避免旧模块混入安装包。

验证范围为本地 CLI 自动化测试、模拟 HTTP 请求与真实 Wheel 构建检查；尚未完成真实平台接口联调或 Windows 原生验证。本文描述源码变更，不代表已创建正式 Release 或更新已发布附件。
