# 1.0.7.9 CLI 开发说明（尚未发布）

相较源码 1.0.7.8，新增 `ml service mock SERVICE_ID [-o table|json]`。命令依次查询服务基本信息、查询服务文档和发起一次服务测试。服务名称及版本来自 `serviceInfo`，服务租户来自 `modelInfo.businessId`，请求样例使用文档的 `requestContent` 原文。所有请求的 `businessid` 头取自当前环境选中的业务，接口地址沿用当前环境配置。

使用前须登录、选择业务，并确保目标服务已配置有效的 JSON 请求样例。表格完整展示各节点的主机名称、机器规格、站点、结果码、格式化 JSON 报文和耗时。JSON 输出保留响应的其他字段，将 `mockResponse` 解析为 JSON 值，并新增 `mockResponseRaw` 保留原文。非法报文和失败节点不阻止其他节点结果展示，但会使命令退出码为 1。空节点列表同样作为失败处理。

测试接口外层成功不代表各节点或内部业务均成功。节点结果码和报文解析全部成功才退出 0，报文内业务状态仍需使用者核对。必要信息缺失、文档服务或租户信息冲突时停止；认证失败不自动重放测试，超时或断连后执行结果可能未知，不自动重发。

已有命令语法兼容。权限服务、本地通知助手及数据库结构未修改，无需数据库迁移。本次仅更新 CLI 源码及本地包，不发布正式 Release、Windows 安装包或 Docker 镜像，正式下载入口继续使用 1.0.7.7。真实平台服务联调、Windows 安装及正式发布工作流尚未验证。

本地验证：Python 3.12 环境下 CLI 测试 1141 项通过、12 项跳过，权限服务测试 259 项通过、1 项跳过，浏览器时区测试 3 项通过。新增测试覆盖三次请求的字段来源与顺序、当前业务请求头、多个节点、完整缩进报文、未知字段保留、无效 JSON、空节点、前置校验及认证失败和超时不重放。手册全部 32 章结构、命令帮助与实际命令树检查通过；独立安装的 Wheel 元数据、包内版本和 `ml --version` 均为 1.0.7.9，新增模块与随包命令索引已核验。跳过项目不视为已验证。
