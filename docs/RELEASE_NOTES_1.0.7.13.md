# CLI 1.0.7.13 — 宽表特征集装配质量查询

本次为源码更新，尚未正式发布。相较 CLI 源码 1.0.7.12，新增质量监控报告中宽表特征集的四个只读查询命令。上一正式发布版本仍为 1.0.7.10，现有正式下载入口不变。本次只递增 CLI，权限管理系统、Agent、权限通知助手及 Agent 已验证 CLI 搭配版本保持原值。

## 新增能力

- `ml quality wide-featureset feature-assemble list --set-id SET_ID` 查询特征装配样本定义。
- `ml quality wide-featureset label-assemble list --set-id SET_ID` 查询标签装配样本定义。
- 对应分组的 `feature list --set-id SET_ID --definition-id DEFINITION_ID` 分页查询样本定义下的特征，默认第 1 页、每页 10 条，最多 100 条。
- 装配列表展示样本定义 ID、名称、输出表、最新周期、正负样本比例；特征列表展示特征 ID、名称、类型、值类型、对应装配最新周期、空值率。
- 新命令表格比例按整数四舍五入展示，如 0.1538 为 15%、0.017 为 2%、0.125 为 13%；现有特征质量列表的小数百分比展示保持不变。
- JSON 保留记录全部原始字段、数值与空值；装配样本定义列表不分页，count 仅表示本次返回条数，响应包含 featureSetId 时供调用者核对。返回 ID 与请求不同不会自动替换后续查询参数。
- 请求沿用当前环境认证、业务选择与权限校验，businessid 来自当前环境的 selected.businessId；同步使用手册及平台 skill 的查询指导。

## 使用前提与兼容性

需先配置环境、登录并选择业务，平台需提供对应装配质量查询接口。新增命令不涉及数据库结构变更，不执行生产升级。现有命令与配置兼容。

CLI Wheel 元数据和运行版本目标均为 1.0.7.13；本地验证包不属于正式发布附件。Windows 联网安装要求 Python 3.9+；离线包目标仍为 Windows x64 / Python 3.12，不包含 Python 或 Edge 本体。权限系统镜像不包含 MySQL 或 Jupyter Server。本次未生成正式 Windows 包或镜像。
