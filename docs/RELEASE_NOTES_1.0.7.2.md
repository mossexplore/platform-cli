# 1.0.7.2 开发说明（尚未发布）

新增 `ml context [--json]`，无需登录即可核对实际运行模式、平台环境和配置路径。新增独立演示扩展与打包入口，两套环境使用同名 `ml`，不修改终端标题和提示符。

演示支持持久化模拟业务、接口故障场景、实际文件产物，以及可选的本地 Jupyter 实际执行。正式包不依赖或自动加载演示扩展，构建后检查归档，阻止 mock 文件混入。原 Windows 正式构建入口保持不变。

CLI 与权限服务版本元数据同步；本次未改变权限服务数据库 schema。为保持既有 Click 异常处理契约，Typer 依赖限定为小于 0.26，避免新版内置解析器异常类型导致参数错误变成运行错误。

设计见 [设计方案](CLI模拟数据与独立演示环境设计方案.md)，操作见 [演示指南](CLI演示环境使用指南.md)，验证范围见 [测试报告](CLI演示环境测试报告.md)。源代码和本地测试不等于正式发布；正式 Release 仍须运行仓库规定的 Windows、镜像和草稿复核流程。

演示业务调用必须通过真实权限管理系统，初始化显式指定服务和账号。权限及版本策略不再模拟；依赖离线安装不代表运行可以脱离权限服务。
