# CLI 1.0.7.14 — 权限服务 CA 来源配置

本次为源码修复，尚未正式发布。相较 CLI 源码 1.0.7.13，解决公共证书权限服务被 Agent 注入的 CA 环境变量干扰的问题。上一正式发布版本仍为 1.0.7.10，正式下载入口不变；仅递增 CLI，其他组件和 Agent 已验证搭配版本保持原值。

## 修复与配置

- 新增 `access_control.ca_source`：`certifi` 显式使用公共 CA 并忽略 `SSL_CERT_FILE`、`SSL_CERT_DIR`；`env` 保留环境 CA 行为；`custom` 使用 `access_control.ca_file` 指定的绝对路径 PEM CA 文件。
- 随包配置显式选择 `certifi`。已有外部配置省略该字段时仍使用 `env`，公共证书部署需在实际使用的配置中显式添加 `"ca_source": "certifi"`。既有安装器仍按原规则同步随包配置；自定义外部配置不自动迁移，不应假定仅更新源码就会改变 Windows 已安装副本。
- 三种模式用于业务权限检查、账号授权摘要和批量环境授权查询。CA 来源与环境代理开关独立，不改变平台业务客户端，不修改系统或 Agent 证书，不自动清空进程变量。
- 证书和主机名校验始终保留，不自动合并或回退其他信任库；私有 CA 部署应显式选择 `env` 或 `custom`。无法加载的 CA、无效来源、缺失或相对路径 custom 文件以及不匹配的 ca_file 参数均报配置错误。
- TLS 校验失败、域名解析失败与超时提供分类提示；`ml access status --diagnose` 展示 CA 来源，不回显原始异常或证书路径。同步用户手册和两套 skill 的排障指导。
