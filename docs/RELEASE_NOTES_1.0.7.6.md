# 1.0.7.6 CLI 开发说明（尚未发布）

新增 `ml sample-task period list TASK_ID`，查询新版样本任务的执行周期。支持分页、北京时间起止日期与多状态筛选，默认每页 20 条，以无表头四列网格展示，最后一行补空格。

新增 `ml sample-task execution list TASK_ID`，查询新版样本任务执行记录，默认每页 10 条，可通过 `--include-history` 包含历史实例。表格转换状态、大小、分钟时长及北京时间；JSON 保留原始记录。

两个命令均直接使用任务 ID，需先选择环境、登录并选择业务。原有样本任务列表仍默认使用旧任务管理。CLI 补丁版本递增，权限服务和数据库结构未修改。

验证范围为模拟 HTTP、CLI 自动化和本地 Wheel 检查，未进行真实平台及 Windows 原生联调，未发布正式 Release。
