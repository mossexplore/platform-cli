# CLI 1.0.7.12 — 质量监控报告查询

本次为 CLI 源码更新，尚未执行正式发布。相较源码 1.0.7.11，新增 Web 管理台“质量监控报告”下的两个只读分页查询入口；上一正式发布版本为 1.0.7.10，正式下载入口保持不变。权限管理系统调整页头的版本展示和版本来源；通知助手增加“高级设置”同一行右侧版本展示，数据库结构未变更。

## 能力与使用前提

- `ml quality feature list` 查询特征质量信息，支持特征名称、特征表名、特征值类型和指标类型筛选。类型接受中文名称与英文枚举，英文忽略大小写，未指定类型时省略该请求字段。
- `ml quality wide-featureset list` 查询质量监控宽表特征集，支持特征集名称筛选，与现有 `ml featureset wide list` 的接口及输出内容不同。
- 默认第 1 页、每页 10 条，每页最多 100 条；一次只查询指定页，分页信息优先采用接口实际返回值。
- 先选择环境、登录并选择业务；请求必须携带当前环境 `business.json` 中的 `selected.businessId`，与业务上下文不一致时停止查询。
- 表格完整展示首列 ID，翻译类型、按百分比显示空值率；特征产出周期与时效性数值保留原值。宽表带时区时间转换为北京时间。
- `-o json` 输出 `items`、`count`、`pageIndex`、`pageSize`，保留记录的全部原始字段和值，不执行表格格式转换。
- 同步用户手册、简洁及详细 Agent 命令索引，详细索引覆盖 98 个命令。
- Agent 新增 `list_quality_features`、`list_quality_wide_featuresets` 两个只读业务工具，归入 `quality` 发现领域，复用同一 CLI Service，分别映射真实 CLI 权限命令；支持中文和英文枚举，分页继续受 Agent 管理员配置限制。业务工具总数为 90，覆盖 80 个 CLI 业务叶子命令。
- Agent 另增 `list_feature_null_rates`，复用特征查询的筛选、分页和权限，只返回 `nullValueRates` 原始数值数组与分页信息。缺失值保留 null，重复值保留；提取先于输出预算检查，避免无关长字段影响数值获取。每次只查一页，全量统计需翻页；不新增 CLI 命令或数据库结构。

- Agent 的退出登录按钮移至右上角，采用与权限管理系统一致的图标和文字，移除“写入需确认”提示。两套页面均在退出图标左侧显示当前版本；各产品均读取自身包内版本，避免依赖版本被误作产品版本。窄屏保留版本与退出入口，退出确认逻辑沿用原行为。

- 四个产品的目标版本统一由根目录 `versions.toml` 管理，本次均为 1.0.7.12，后续可独立递增；同步脚本维护打包元数据及运行版本，CI 检查一致性。Agent 单独记录已经测试搭配的 CLI 版本，通知助手在页面左下角“高级设置”同一行右侧显示自身版本。来源与操作见 [版本号管理说明](版本号管理说明.md)。

## 安装与兼容性

CLI 包元数据及 `ml --version` 目标均为 1.0.7.12。本地 Wheel 用于验证，不等于正式发布附件。现有配置与命令兼容，无数据库迁移要求。Windows 联网安装仍要求 Python 3.9+，离线包目标仍为 Windows x64 / Python 3.12；CLI 离线包不包含 Python 或 Edge 本体。权限系统镜像不包含 MySQL 或 Jupyter Server。
